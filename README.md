# Prompt Library

画像生成用のプロンプトを、タグやブロックとして整理・組み立てるブラウザーアプリです。

## ▶ [アプリを開く](https://arvelt.github.io/prompt-library/)

## 主な機能

- **Prompt**：タグ・ブロックを選び、Positive / Negativeのプロンプトを作成
- **Library**：カテゴリ・サブカテゴリごとにタグ・ブロックを管理
- **Promptセット**：複数のプロンプトを名前付きで保存・切替
- **PNG Info**：PNG内の生成情報を読み取り、プロンプトへ送信
- **JSON Export / Import**：全データ、またはPromptセット単体をバックアップ・復元
- **日本語 / English**：表示言語を切替
- **タグの表示名・説明**：Prompt本文と別に保存し、一覧表示・検索・JSONバックアップに対応
- **ブロックの保存**：本文から未登録タグを同じ保存先へ自動追加。既存タグは同じPositive / Negativeライブラリ内で再利用
- **ブロックのコピー**：本文だけをクリップボードへコピー
- **GitHubで表示**：画面右端のリンクからリポジトリを開く

ブロックのタグ解析ではカンマと改行で区切り、空の項目と重複を除きます。括弧内・LoRA構文内の区切りやエスケープされた区切りは保持します。自動追加したタグの表示名・説明は空欄で、後から編集できます。

## データの保存・バックアップ

LibraryやPromptセットは、使用中のブラウザー内に保存します。サーバーには保存しません。

保存データはブラウザー・端末ごとに別で、自動同期はありません。ブラウザーのサイトデータを削除すると失われるため、必要なデータはJSON Exportでバックアップしてください。別の端末・ブラウザーへの移行にも使用できます。

## Importについて

- **全データImport**：現在のLibraryと全Promptセットを置き換えます。
- **Prompt単体Import**：Libraryを変更せずに取り込みます。同名セットがある場合は、別名追加・上書き・キャンセルを選択できます。

## 公開・更新

GitHub Pagesの `main / (root)` から公開しています。ルートの `index.html` を更新し、mainへpushすると公開サイトに反映されます。

## 検証

Node.jsの標準テストでデータ互換性・タグ解析・重複防止・コピーを検証できます。

```sh
node --test tests/library.test.cjs
```

PlaywrightとGoogle Chromeを利用できる環境では、保存・編集・選択タグからの作成・PNGからの登録・検索・再読み込み・クリップボード・英語表示・モバイル幅のブラウザー操作も検証できます。新しいブラウザーコンテキストを使うため、通常利用中の保存データは変更しません。

```sh
node tests/browser.test.cjs
```
